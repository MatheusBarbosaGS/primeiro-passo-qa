# Primeiro Passo em QA

Guia descomplicado para quem quer entrar na área de Qualidade de Software, feito por [Matheus Barbosa](https://www.linkedin.com/in/matheusbgs).

## Páginas

| Arquivo | Endereço | Conteúdo |
|---|---|---|
| `index.html` | `/` | O que é QA, trilha de estudos em 6 níveis com checklist e Sobre |
| `ferramentas.html` | `/ferramentas` | Ferramentas por categoria |
| `certificacoes.html` | `/certificacoes` | CTFL e AWS Cloud Practitioner |
| `pratica.html` | `/pratica` | Sites para praticar e projeto guiado de portfólio |
| `carreira.html` | `/carreira` | Níveis, trajetória, currículo e entrevistas |
| `glossario.html` | `/glossario` | Glossário pesquisável |

- `styles.css`: estilos compartilhados por todas as páginas
- `vercel.json`: ativa os endereços sem `.html`
- `favicon.svg`: ícone da aba

Site estático, sem build. Hospedado na Vercel.
