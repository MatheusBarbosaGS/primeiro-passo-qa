# Primeiro Passo em QA

Guia descomplicado para quem quer entrar na área de Qualidade de Software: trilha de estudos em 6 níveis com checklist de progresso, ferramentas, certificações, portfólio, carreira e glossário.

Feito por [Matheus Barbosa](https://www.linkedin.com/in/matheusbgs).

## Estrutura

- `index.html`: o site inteiro (HTML, CSS e JavaScript em um arquivo)
- `favicon.svg`: ícone da aba

Site estático, sem build. Hospedado na Vercel.
