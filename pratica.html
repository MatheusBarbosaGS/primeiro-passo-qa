Projeto guiado: seu primeiro portfólio

Um único projeto bem feito, do manual à automação, conta mais do que dez tutoriais pela metade.

  1. Escolha um sistema e escreva o plano de testeUse o Sauce Demo. Defina o que será testado (login, carrinho, checkout), o que fica de fora e quais riscos você enxerga.
  2. Escreva 15 a 20 casos de teste em GherkinInclua caminhos felizes e negativos: senha errada, carrinho vazio, campos obrigatórios em branco.
  3. Execute e reporte os bugs que encontrarO site tem usuários com problemas propositais. Escreva os bug reports no modelo "Aprovado" da seção O que é QA.
  4. Automatize os cenários principaisCom Selenium e Java, usando Page Objects e Cucumber para ligar os cenários Gherkin ao código.
  5. Adicione testes de APICrie uma coleção no Postman para o ServeRest e, depois, automatize os mesmos testes com RestAssured.
  6. Rode tudo numa pipeline e capriche no READMEConfigure o GitHub Actions para rodar os testes a cada push e explique no README como executar o projeto.
